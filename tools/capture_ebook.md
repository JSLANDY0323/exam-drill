# 電子書截圖工具

## 背景版：單螢幕也能同時做其他事

雙擊 `tools/capture_ebook_background.cmd` 即可執行。需要已安裝 Python 與 Chrome；第一次會把 Playwright（和缺少時的 Pillow）安裝在專案的 `private/.ebook_capture_packages/`，不更動全域 Python 套件。目前這台電腦已安裝完成。預設以本次提供的 TOEIC 聽力書籍為截圖目標。

1. 工具會用獨立暫存設定檔開啟**一般 Chrome 視窗與博客來首頁**，與平常 Chrome 的登入分開。請在新視窗登入博客來、從電子書櫃開書、移到起始頁，並關閉教學／提示。視窗可以正常調整大小。
2. 回到終端機按 **Enter**，再輸入第一批張數（建議先試 **3 張**）。工具直接對閱讀器頁面翻頁和截圖，不需要 F8 框選範圍。
3. 截圖時可以切到平常的 Chrome、Word 或其他程式工作，讓其他視窗蓋住工具的 Chrome 即可。**先不要最小化、關閉或操作工具的 Chrome**，電腦也要保持喚醒。
4. 要提早停止：回到終端機按 **Enter**，存完目前這張就停。
5. 每批結束（或中途停止、翻頁失敗）後**不會關閉**，會出現選單：
   - 輸入數字：再截幾張，從上次存的下一頁接著截，檔名編號也接續。若你在 Chrome 自己翻到別頁，就從畫面上那頁開始。
   - `s`：修改截圖大小（見下方）。
   - `q`：結束，關閉工具的 Chrome 並清除暫存設定檔。

每次執行都使用一般瀏覽模式的獨立暫存設定檔，結束後關閉並清除該次登入資料；不會讀取或複製平常 Chrome 的登入資訊。工具是直接啟動一般 Chrome，等按下 Enter 後才連線控制，所以登入時網站不會把它當成自動化瀏覽器（之前由 Playwright 啟動的版本會被博客來擋下登入）。若直接開書顯示「發生錯誤(210)，請重新登入」，請在工具的新視窗登入後，從書櫃重新開書，不能只依靠原本 Chrome 的登入。

### 截圖大小

選單輸入 `s` 可隨時修改，下一批生效：

| 設定 | 預設 | 說明 |
|---|---|---|
| 裁掉書頁四周空白 | 開 | 去掉閱讀器的灰白底色，只留書頁（雙頁顯示時留兩頁）。書頁本身的白邊會保留。 |
| 清晰度倍率 | 1 | 1＝跟螢幕一樣；2＝兩倍像素，字比較清楚、檔案較大。視窗大小不變。 |
| 輸出寬度 | 0 | 0＝不縮放；填像素（例如 1200）會等比例縮放成這個寬度。 |

書頁在截圖裡的大小也取決於工具 Chrome 視窗的大小，建議最大化。

### 指令列參數

在專案資料夾開啟 PowerShell：

```powershell
py -X utf8 tools/capture_ebook_background.py --pages 20 --delay 2 --scale 2 --width 1200
```

`--pages` 是第一批張數（之後可在選單追加），`--delay` 是翻頁後至少等待幾秒（預設 2），`--scale`、`--width` 見上表，`--no-trim` 不裁空白，其他書籍加 `--url "閱讀器網址"`。

圖片輸出到 `private/ebook_captures/日期時間/`，依序為 `page-0001.png`、`page-0002.png`。畫面若顯示雙頁，一張 PNG 就包含兩頁；檔名序號不是書上的頁碼。同一資料夾的 `log.txt` 記錄翻頁方式的切換與停止原因。

翻頁依序嘗試：點翻頁按鈕 → 直接觸發按鈕事件 → 右方向鍵，哪一種讓畫面改變就繼續用那一種。三種都沒讓畫面改變（書末、跳出提示）會停在選單，已存圖片保留。這是像素檢查，不會辨識書頁碼；先試截並檢查清晰度、順序與完整性。截圖時暫時隱藏工具列與翻頁按鈕；不做 OCR。

`private/` 已由專案 `.gitignore` 排除，仍依 Google Drive 設定同步。圖片與套件都不應加入公開版控。

### 驗證狀態

已用模擬閱讀器（一般 Chrome＋CDP 連線）驗證：連續截圖與追加批次接續編號、不重複存同一頁、按 Enter 中途停止、按鈕被遮住時改用按鈕事件、只認方向鍵時改用方向鍵、書末停在選單、裁白邊、2 倍像素與輸出寬度。登入流程：工具開的 Chrome `navigator.webdriver` 為 false、博客來登入頁正常顯示；結束後暫存設定檔會刪除。

**尚未在博客來實際書頁驗證**（需要使用者登入）：哪種翻頁方式有效、雙頁顯示時的裁切，以及被其他視窗蓋住時翻頁是否正常。

## 截圖合併成 OCR 用 PDF

```powershell
py -X utf8 tools/ebook_to_pdf.py "private/ebook_captures/聽力/聽力題本"
```

每頁先用 Lanczos 放大 3 倍，再以 300 DPI 的實際尺寸（約 17.5×24.6 cm）放進 PDF，輸出在資料夾旁的「資料夾名（OCR用）.pdf」。可給多個資料夾，依序合併成一本。

- 為什麼要放大：倍率 1 的截圖書頁只有約 690 像素寬，中文字約 11 像素高，OCR 會出現「舄／寫」「冃／目」這類形近錯字。實測同一頁放大後，英文不再黏字，中文「反磢→反映」「出舨→出版」等也認對。
- 放大只能讓 OCR 讀得比較好，不會補回細節。最好的做法是截圖時就用清晰度倍率 3；那種截圖合併時加 `--scale 1`。
- 只取部分截圖（分題本／詳解、跳過壞頁）：`--pages 1-322`、`--pages 323-640,642-919`，數字是截圖檔名編號，搭配 `--out` 指定檔名。
- 其他參數：`--dpi`（預設 300）、`--quality`（JPEG 品質，預設 92）、`--png`（無損，檔案約大 2.5 倍）、`--out`。

## 原本的前景版

若要沿用不需額外套件的 Windows 截圖，可執行：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\capture_ebook.ps1 -Pages 3 -Delay 2
```

前景版需要鍵盤右方向鍵可翻頁。依提示把滑鼠移到書頁左上角、右下角各按一次 F8，5 秒後開始。按住 F10 可停止。它會占用螢幕與鍵盤，執行期間不能切去做其他事；切換視窗便停止。
