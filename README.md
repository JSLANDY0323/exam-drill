# Exam Drill：多益閱讀刷題

這是練習 TOEIC 閱讀 Part 5、6、7 的網站，打開網頁就能作答，程式介面由 Claude Code 完成。

網址：<https://jslandy0323.github.io/exam-drill/>

## 題庫

| 部分 | 內容 | 題數 |
|---|---|---|
| Part 5 句子填空 | 依考點分階段練習（詞性、連接詞、代名詞、動詞、搭配語意、進階文法）與綜合模擬 | 3,583 |
| Part 5 單字題 | Day 1–30，每天 60 題 | 1,800 |
| Part 6 段落填空 | Test 1–17 | 272 |
| Part 7 閱讀測驗 | Test 1–8，另有雙篇、三篇閱讀練習 | 457 |

題目都是原創，沒有抄襲他人的題目，如有雷同純屬巧合。每題附中文翻譯和詳解，Part 5 另外說明解題線索，以及每個錯誤選項錯在哪裡。

## 作答與檢討

- Part 6、7 採左右分欄，左邊是文章、右邊是題目，檢討時可以逐句對照英文和中文翻譯。
- 檢討時把滑鼠停在英文單字上約 1 秒，會顯示詞性和中文意思，常見片語則會整組標出，手機直接點字即可。
- 提示框裡可以把單字或片語存成單字卡，卡片會附上原句和出處題目。「今日任務」列出今天和昨天存的卡片，翻過一次就算完成，也可以反查這個字在題庫哪些題目出現過。
- 每題都能寫筆記，支援 Markdown 和 LaTeX，寫過筆記的題目會在 1、3、7、14 天後排進「筆記複習」。
- 錯題分析依考點統計正確率，找出比較弱的題型。
- 隨機抽考可以從錯題、標註過的題目、有筆記的題目或全部題目抽題，題數自己設定，Part 5 還能依實際考試的題型比例出題。
- 刷題統計會記錄每題花的時間，用圖表顯示每天的正確率和平均作答時間。
- 支援深色模式，手機和電腦都能用。

## 作答紀錄存在哪裡

作答紀錄、筆記和單字卡都存在你自己的瀏覽器裡，不會上傳。換瀏覽器、換裝置，或清除網站資料後，紀錄就不會跟著過去。

## 在自己電腦上執行

整個網站只有一個 `index.html` 加上 `data/` 裡的題庫，不需要 Node.js，也沒有建置步驟。不過瀏覽器不允許直接開啟本機檔案讀取題庫，所以要先開一個本機伺服器：

```powershell
py -m http.server 8000
```

再用瀏覽器開 <http://localhost:8000>。Windows 也可以直接雙擊 `本機預覽.bat`。
